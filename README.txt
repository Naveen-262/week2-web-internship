Week 2 Web Application Internship Project

FILES
- index.html: website structure
- style.css: design and responsive layout
- script.js: button alert, mobile menu, and form validation
- images/: SVG illustrations used by the page
- report.pdf: project report
- presentation.pptx: 7-slide presentation
- screenshots/: instructions for adding real browser screenshots

HOW TO RUN
1. Extract the ZIP file.
2. Open the Week2-Web-Internship folder in VS Code.
3. Open index.html in a browser. You can use the Live Server extension if installed.
4. Test the Say hello button, navigation menu, and contact form.

BEFORE SUBMISSION
- Confirm the name and personal details in the website/report.
- Replace the sample contact information if you want to share real details.
- Capture 2–3 genuine screenshots and place them in the screenshots folder.
- The form is a frontend demo and does not send messages to a server.
